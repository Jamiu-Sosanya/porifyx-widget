1 AI Conversation Engine

The AI engine is the brain of every widget. It reads your uploaded content, understands visitor questions, and generates accurate answers — in real time, 24/7, without human involvement.

What it means in plain language

Imagine hiring an employee who has read every page of your website, every product manual, and every FAQ document you have. They never forget anything, never go on holiday, and can handle thousands of customers simultaneously. That is what the AI engine does — automatically.

Supported AI Providers

OpenAI GPT-4o

The most capable model for complex, multi-step questions. Best overall quality. Widely regarded as the industry standard.

Anthropic Claude

Excellent at reading long documents and providing nuanced, thoughtful responses. Great for legal, medical, or detailed technical content.

Google Gemini 1.5 Flash

Extremely fast and cost-effective. Ideal for high-traffic sites where speed and cost per conversation matter most.

Groq Llama 3.1

Ultra-fast inference, often responding in under one second. Best for simple, quick Q&A applications.

RAG — Retrieval-Augmented Generation

The platform uses a technique called RAG which means the AI does not make up answers. Instead, before responding, it searches your uploaded knowledge base for the most relevant information, then uses that content as the basis for its answer. This prevents the AI from saying something inaccurate or "hallucinating" facts that are not true.

💡

Example: A visitor asks "What is your return policy?" The AI searches your uploaded return-policy document, finds the relevant paragraph, and quotes it back accurately — not a made-up answer.

Conversation Features

  • Streaming responses — text appears word-by-word like a real person typing, which feels more natural and engaging
  • Smart suggestions — after each AI answer, 2–3 relevant follow-up question buttons appear to guide the conversation
  • Conversation starters — pre-written opening questions shown when a visitor first opens the chat
  • Typing indicators — animated dots showing the AI is "thinking", reducing visitor impatience
  • Message reactions — visitors can react to messages with emoji
  • File attachments — visitors can upload files (images, PDFs) during a conversation
  • Voice input — speech-to-text so visitors can speak their question instead of typing
  • Auto language detection — AI detects the visitor's language and responds in the same language automatically
  • Confidence-based fallback — if the AI is not confident enough in an answer, it gracefully escalates to a human or collects the visitor's contact details

AI Personality Controls

  • Custom AI name and avatar — name your AI "Aria", "Max", or anything that fits your brand
  • Tone presets — choose Friendly, Professional, Sales-Focused, or Technical to match your audience
  • Custom system prompt — write specific instructions for how the AI should behave (e.g. "Always ask for the visitor's budget before discussing pricing")
  • Confidence threshold — set how certain the AI must be before answering (higher = more cautious, fewer wrong answers)

2 Widget Builder & Customisation

Every detail of your chat widget's appearance and behaviour is configurable without writing a single line of code.

Visual Appearance

  • 6 built-in themes — Light, Dark, Minimal, Bold, Ocean, Nature — each changes colours, fonts, and button styles together
  • Custom primary colour — match your brand's exact hex colour code
  • Font selection — choose from Inter, Poppins, and other modern typefaces
  • Launcher button style — circle, square, or rounded rectangle; choose position: bottom-right, bottom-left, etc.
  • Header design — upload your logo, set an AI avatar image, choose gradient colours
  • Mobile-specific controls — separately hide or show the widget on small screens

Behaviour Settings

  • Auto-open after N seconds — the widget pops open automatically after the visitor has been on the page for a set time
  • Auto-open on page count — opens after the visitor visits a certain number of pages
  • Domain restriction — your widget only works on approved domains, preventing others from copying your embed code
  • Rate limiting — limits how many messages a single visitor can send per minute to prevent abuse
  • Session persistence — conversations resume from where they left off, even after the visitor refreshes the page
  • Sound notifications — play a soft sound when a new AI message arrives

Proactive Messaging

Instead of waiting for a visitor to open the chat, you can proactively send them a message based on their behaviour:

  • Time on page trigger (e.g. "You have been here for 30 seconds — can I help?")
  • Exit intent trigger (e.g. message appears when mouse moves toward the browser close button)
  • Page count trigger (e.g. after 3 pages, show a relevant offer)
  • URL pattern trigger (e.g. only show on pages matching /pricing*)

Lead Capture Form

  • Toggle which fields to collect: name, email, phone, company
  • Choose whether collection happens before or during the conversation
  • Set a custom lead capture message
  • Always-capture mode: saves visitor details even if they do not complete the form

Embedding on Your Website

After creating a widget, you get a single line of HTML. Paste it anywhere on your site — before the closing </body> tag — and the widget appears instantly.

<script src="https://yourdomain.com/widget.js?id=abc123" defer></script>

Works on WordPress, Shopify, Webflow, Squarespace, Wix, plain HTML, React, Vue — any platform that allows custom HTML/scripts.

3 Knowledge Base & AI Training

Your AI is only as good as the information you give it. The knowledge base is where you upload, organise, and manage all the content that your AI learns from.

What You Can Upload

📄

PDF Files

Upload product manuals, brochures, contracts, or any PDF document. The system extracts and indexes all text automatically.

🌐

Website URLs

Paste any web page URL. The system crawls the page and extracts all the text content for training.

🗺️

Sitemaps

Provide your sitemap.xml URL and the system will automatically crawl and train on every page of your website at once.

✍️

Text Snippets

Type or paste any text directly — product descriptions, policy text, custom Q&A pairs — without needing an external file.

❓

FAQ Format

Add structured Question and Answer pairs. This is the most precise way to control exactly what the AI says for specific questions.

🔄

Auto-Refresh

URLs can be set to auto-refresh so that if your website content changes, the knowledge base stays current without manual re-training.

How Training Works (Plain Language)

When you add content, the system breaks it into small chunks (paragraphs) and converts each chunk into a mathematical fingerprint called an embedding. When a visitor asks a question, their question is converted into the same type of fingerprint and compared against all chunks. The most similar chunks are retrieved and handed to the AI as context for its answer.

ℹ️

You do not need to understand embeddings to use the knowledge base. Just upload your documents and click Train. The system handles everything automatically.

Version Control

Every time you retrain, the previous knowledge base version is preserved. If a new training run produces worse results, you can roll back to an earlier version with one click.

Multiple Knowledge Bases per Widget

You can create several knowledge base versions for the same widget (e.g. one for product info, one for support FAQs) and switch the active one at any time without affecting the widget embed code.

4 Lead Capture & Scoring

Every conversation is an opportunity to identify a potential customer. The platform automatically extracts contact details and assigns a quality score to each lead — without any manual work.

Automatic Information Extraction

The AI reads the entire conversation and extracts:

  • Name, email address, phone number
  • Company name and website
  • Service or product interest
  • Budget range and timeline
  • Pain points and current problems
  • Purchase urgency signals

This happens invisibly in the background. The visitor never needs to fill out a form — just chat naturally.

Lead Scoring (0–100)

Every lead receives a score from 0 to 100 based on:

  • How much contact information was shared
  • Whether a budget was mentioned
  • Purchase intent language used ("I want to buy", "looking to switch", "comparing options")
  • Urgency signals ("need it by next week", "launching soon")
  • Engagement depth (longer conversations = higher intent)

🔥 Hot Lead (80–100)

Ready to buy. High intent, budget confirmed, timeline is near. Should be contacted within the hour.

🌡️ Warm Lead (50–79)

Interested but not urgent. Needs follow-up within 24–48 hours with a personalised message.

❄️ Cold Lead (0–49)

Early-stage research. Add to a nurture sequence and check back in 2–4 weeks.

Lead Management

  • View all leads in a searchable, filterable table
  • Add internal notes visible only to your team
  • Update lead status: New → Contacted → Qualified → Won / Lost
  • Assign leads to specific team members
  • Export leads to CSV for import into any CRM (HubSpot, Salesforce, Pipedrive, etc.)
  • See the full conversation that generated each lead

How It Works

  1. 1

    Connect a Channel

    In your widget settings → Channels tab, click Add Channel and select the platform. A form appears asking for the credentials specific to that platform (e.g. a bot token for Telegram, an access token for Facebook).

  2. 2

    Register the Webhook

    After saving, the platform shows you a webhook URL. You copy this URL and paste it into the messaging platform's developer settings. This tells the platform "when a message arrives, send it to this URL".

  3. 3

    Test the Connection

    Click the Test button. The platform sends a test message to verify the connection is working. A green tick confirms success.

  4. 4

    Go Live

    Toggle the channel to Active. From this point, any message a user sends on that platform is routed through the AI and answered using your knowledge base.

  • Live chat takeover — any team member can take over from the AI at any point and reply as a human
  • Hand-back to AI — when the human is done, they hand the conversation back to the AI with one click
  • Conversation summary — AI automatically generates a bullet-point summary of the key points after each conversation
  • Action items — the AI suggests next steps based on the conversation content
  • Labels and tags — apply custom tags (e.g. "pricing", "technical issue", "enterprise") for organisation and filtering

8 Automations & Workflows

Automations let the platform take action automatically when something important happens — without you needing to be watching. Think of them as "if this happens, do that" rules.

When Can an Automation Fire? (Triggers)

  • A new lead is captured
  • A lead score exceeds a threshold (e.g. "if lead score > 80")
  • A visitor requests a human agent
  • A conversation is resolved
  • A keyword is detected in a message (e.g. "competitor", "cancel", "refund")
  • A visitor submits the offline message form

What Can It Do? (Actions)

  • Send an email — notify a team member with a custom message including lead details
  • Send a Slack message — post an alert to a Slack channel with a summary
  • Send a Discord message — post to a Discord webhook
  • Send a webhook — POST the lead or conversation data to any external URL (connects to Zapier, Make.com, HubSpot, Salesforce, etc.)
  • Tag the conversation — automatically apply a label for organisation
  • Update lead status — move a lead to a different status automatically
💡

Real-world example: Set up a rule: "When a lead score exceeds 85, send a Slack message to the #sales channel with the lead's name, email, phone, and a link to the conversation." Your sales team gets notified instantly every time a hot prospect appears.

9 A/B Testing

A/B testing (also called split testing) lets you run two slightly different versions of your widget at the same time and see which one converts more visitors into leads.

What Can Be Tested?

  • Different greeting messages (e.g. "Hi! Can I help you?" vs "What brings you here today?")
  • Different widget colours or themes
  • Different AI tone settings (friendly vs professional)
  • Different conversation starter questions
  • Different proactive message timing

How It Works

You define Variant A and Variant B. The platform randomly assigns each visitor to one variant and tracks separately: how many conversations each generates, how many leads each produces, and which has a higher conversion rate. A statistical confidence score tells you when the test has enough data to call a winner.

Applying the Winner

Once a winner is identified, click Apply Winner to make that version the permanent configuration for your widget. All traffic then uses the winning variant.

The dashboard can be installed as a native-feeling app on phones and computers, with push notifications so your team gets alerted in real time even when the browser is closed.

  • Add to home screen — install like any iOS/Android app from Safari or Chrome
  • Standalone mode — runs without browser navigation bars for a clean app experience
  • Push notifications — get instant alerts when a hot lead arrives, when a visitor requests a human, or when an offline message is submitted
  • Offline mode — a branded offline page loads when connection is lost, then auto-refreshes when connection returns
  • Background sync — data updates automatically in the background when reconnected

13 API & Webhooks

  • REST API — programmatic access to widgets, conversations, leads, and channel data
  • API Keys — generate personal API keys from Settings → API Keys
  • Outbound webhooks — send real-time events to your own systems when leads, conversations, or channel messages occur
  • Inbound webhooks — channel platforms send messages to your webhook URLs which are processed by the AI automatically
  • Webhook logs — full history of every webhook sent and received with request/response bodies and status codes

14 Security

  • Bcrypt password hashing — passwords are never stored in plain text
  • CSRF protection — all forms are protected against cross-site request forgery
  • Encrypted credentials — channel API keys and secrets are stored encrypted in the database (Laravel encrypted model casting)
  • Domain allowlisting — widgets only work on your approved domains
  • Rate limiting — API and widget endpoints have configurable rate limits
  • Input validation — every form input is validated and sanitised
  • SQL injection prevention — all queries use Laravel's parameterised query builder
  • XSS protection — Blade templates auto-escape output
  • Soft deletes — data is never permanently deleted immediately; a 30-day recovery window exists
  • Activity logging — every significant admin and user action is recorded with IP, user, and timestamp

  • Custom AI names — per widget, give the AI any name and avatar that fits the client's brand
