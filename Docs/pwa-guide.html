PWA Guide

PoriFyx Widget is a fully compliant Progressive Web App. This means your team can install the dashboard directly on their phone, tablet, or desktop computer — it will look and feel just like a native app, with push notifications for new leads and conversations, and full offline access to recent data.

1 What Is a PWA?

A Progressive Web App (PWA) is a website that has been enhanced to behave like a native mobile or desktop application. You do not download it from the App Store or Google Play — you install it directly from your browser in seconds.

🌐

It Is Still a Website

The app runs on your server — there is nothing extra to install on the server side. Updates happen automatically the next time a user opens the app. No manual app store updates required.

📲

It Feels Like a Native App

It gets its own icon on your home screen, launches full-screen (no browser chrome), and can receive push notifications even when the browser is closed.

💡

Think of it like this: Installing the PWA is like pinning a smart shortcut to your phone's home screen — except it can vibrate your phone when a hot lead comes in, even at 2am when you are not looking at it.

3 Install on Android

Android offers the best PWA support — the installation prompt appears automatically when you visit the dashboard.

Method 1: Automatic Install Banner (Recommended)

  1. 1
    Open Google Chrome on your Android device.
  2. 2
    Navigate to your dashboard URL (e.g. https://yourdomain.com/dashboard) and log in.
  3. 3
    After a few seconds, a banner will appear at the bottom of the screen: "Add PoriFyx Widget to Home screen".
  4. 4
    Tap Add. The app icon appears on your home screen immediately.

Method 2: Browser Menu (if banner did not appear)

  1. 1
    While on the dashboard in Chrome, tap the three-dot menu (⋮) in the top-right corner.
  2. 2
    Tap "Add to Home screen" or "Install app".
  3. 3
    Confirm by tapping Add in the dialog that appears.
  4. 4
    Find the icon on your home screen or app drawer. Tap it to launch the full-screen dashboard.
ℹ️

Compatible browsers on Android: Google Chrome (best support), Microsoft Edge, and Samsung Internet all support PWA installation. Firefox for Android does not currently support PWA install.

4 Install on iPhone / iPad (iOS)

On iOS, you must use Safari to install PWAs — Chrome and other iOS browsers cannot install them. The process uses Safari's "Add to Home Screen" feature.

  1. 1
    Open Safari (not Chrome, not Firefox — must be Safari) on your iPhone or iPad.
  2. 2
    Navigate to your dashboard URL and log in.
  3. 3
    Tap the Share button — the square icon with an arrow pointing upward. On iPhone it is at the bottom of the screen; on iPad it is at the top.
  4. 4
    Scroll down in the Share sheet and tap "Add to Home Screen".
  5. 5
    Optionally rename the app, then tap Add in the top-right corner.
  6. 6
    The icon appears on your home screen. Tap it to launch the dashboard full-screen in standalone mode (no Safari address bar).
⚠️

iOS Push Notification Note: Push notifications on iOS require iOS 16.4 or later. After installing the PWA, you will be prompted to allow notifications the first time you open it from the home screen icon. If you installed it with an older iOS version, update iOS and re-install the PWA to enable notifications.

iOS PWA Limitations

  • The PWA must be opened from the home screen icon (not from Safari) for notifications to work.
  • Background sync is limited on iOS — real-time updates may take a few seconds longer than on Android.
  • iOS Safari does not show an automatic install banner — you must use the Share menu manually every time you want to install.

5 Install on Desktop (Windows & Mac)

On desktop, the PWA installs as a standalone window application. It gets its own taskbar/dock icon and launches without a browser address bar — perfect for agents who use the dashboard all day.

Google Chrome (Windows & Mac)

  1. 1
    Open the dashboard in Google Chrome on your computer.
  2. 2
    Look for the install icon (a computer monitor with a down arrow ⊕) in the browser's address bar on the right side. Click it.
  3. 3
    Click "Install" in the popup that appears.
  4. 4
    The app opens in its own window. A shortcut is added to your Desktop and Start Menu (Windows) or Applications folder (Mac).

Microsoft Edge (Windows)

  1. 1
    Open the dashboard in Microsoft Edge.
  2. 2
    Click the three-dot menu (…) in the top-right corner.
  3. 3
    Select Apps → Install this site as an app.
  4. 4
    Confirm the name and click Install. The app is pinned to your taskbar automatically.

Safari (Mac)

  1. 1
    Open the dashboard in Safari on macOS Sonoma (14) or later.
  2. 2
    From the menu bar, go to File → Add to Dock.
  3. 3
    Confirm by clicking Add. The app icon appears in your Dock.
💡

For team-wide deployment: IT administrators can pre-install the PWA on company computers using Chrome's enterprise management policies (WebAppInstallForceList). This ensures every agent has the app without asking them to manually install it.

6 Enabling Push Notifications

Push notifications alert your team to important events — new leads, live conversation escalations, or messages above a certain urgency threshold — even when the dashboard is not open in a browser tab.

Enabling Notifications (User)

  1. 1
    Install the PWA first (see above). Push notifications require the app to be installed; they do not work from a regular browser tab on most devices.
  2. 2
    Open the installed app from your home screen or desktop icon.
  3. 3
    The app will show a permission prompt: "PoriFyx Widget wants to send you notifications." Click or tap Allow.
  4. 4
    Go to Dashboard → Settings → Notifications to choose exactly which events trigger notifications (see Notification Types below).

If You Accidentally Clicked "Block"

If you denied the notification permission, you need to re-enable it in your device's browser/app settings:

  • Android Chrome: Settings → Site Settings → Notifications → find your domain → Allow
  • iOS (Safari PWA): Settings app → [App Name] → Notifications → Allow Notifications
  • Desktop Chrome: Click the lock icon in the address bar → Notifications → Allow
  • Desktop Edge: Address bar lock → Permissions → Notifications → Allow

Admin: Configuring Push (VAPID Keys)

For push notifications to work, an administrator must configure VAPID keys in the server's .env file. VAPID (Voluntary Application Server Identification) is the standard for web push authentication.

  1. 1
    Generate VAPID keys by running: php artisan webpush:vapid
  2. 2
    Copy the output into your .env file:
VAPID_PUBLIC_KEY=BGz... # Long public key string VAPID_PRIVATE_KEY=4a8... # Long private key string VAPID_SUBJECT=mailto:admin@yourdomain.com
  1. 3
    Run php artisan config:cache to apply the new keys.
  2. 4
    Push notifications are now active. Users who have given permission will start receiving them immediately.
⚠️

VAPID keys are sensitive. The private key should never be shared or committed to version control. If a key is compromised, regenerate new keys and run php artisan config:cache again — all users will need to re-subscribe to notifications after a key rotation.

7 Notification Types

Each user can configure which events they want to be notified about from Dashboard → Settings → Notifications.

Notification EventTriggered WhenDefault
🎯 New Lead CapturedThe AI extracts a name/email/phone from a conversationOn
🔥 Hot Lead (Score ≥ 80)A lead is captured with a quality score of 80 or higherOn
🆘 Conversation EscalatedThe AI or a visitor requests a human agentOn
💬 New Conversation StartedA visitor opens the chat widget for the first timeOff (can be noisy)
⭐ Low CSAT ScoreA visitor rates the conversation 1 or 2 out of 5On
📊 Daily SummaryEnd-of-day report: leads, conversations, top questionsOn
⚡ Automation TriggeredAn automation rule fires (e.g. high-value lead webhook)Off
🔧 Channel ErrorA channel webhook fails or a token expiresOn

Per-Widget Notification Settings

You can also configure notifications per widget. For example, if you have 5 widgets but only care about leads from the "Pricing Page" widget, you can mute notifications from the other four without disabling them globally. Go to Widget Settings → Notifications tab.

Team Members and Notifications

Each team member on your account manages their own notification preferences independently. An agent can choose to receive escalation notifications for widgets they are assigned to, without being notified about all new leads. Managers typically enable all notifications; agents typically enable only escalations and their assigned widget leads.

8 Offline Mode

The PWA includes a service worker that caches key resources locally. This means certain parts of the app remain usable even when your internet connection drops.

What Works Offline

  • Viewing recent conversations (last 50 loaded before going offline)
  • Viewing the leads list (last 100 leads loaded before going offline)
  • Reading the knowledge base item list
  • Accessing your account settings page
  • The app shell (navigation, layout) renders instantly with no network

What Requires Internet

  • Sending or receiving new chat messages (the AI requires internet)
  • Loading new conversations or leads that were not cached
  • Saving any settings changes
  • Viewing analytics charts (live data)
  • Uploading knowledge base documents
ℹ️

When your connection is restored, the PWA automatically syncs any queued actions (e.g. a lead status update you made offline) in the background. You will see a brief "Syncing…" indicator in the bottom-left of the dashboard.

Offline Indicator

When the app detects you have lost internet connectivity, a yellow banner appears at the top of the screen: "You are offline — showing cached data." The banner disappears automatically when the connection returns.

Clearing the Cache

If you experience stale data after an app update, clear the service worker cache:

  • Android: Chrome Settings → Privacy → Clear browsing data → Cached images and files
  • iOS: Settings → Safari → Advanced → Website Data → find your domain → Delete
  • Desktop: Chrome DevTools → Application → Service Workers → click "Unregister", then refresh

9 Uninstalling the App

Uninstalling the PWA removes the home screen icon and clears the local cache. Your account data on the server is not affected.

Android

Long-press the app icon on your home screen → tap Uninstall (or drag to the "Remove" area at the top of the screen). Alternatively, go to Android Settings → Apps → find the app → Uninstall.

iOS

Long-press the app icon on your home screen until icons start jiggling → tap the × button in the corner of the icon → confirm deletion.

Desktop (Chrome / Edge)

Open the installed app → click the three-dot menu in the app's title bar → select Uninstall. On Windows, you can also uninstall from the Start Menu or Control Panel → Apps.

10 Troubleshooting

ProblemLikely CauseFix
"Install" option not appearing in browser Site is not served over HTTPS, or manifest/service worker has an error Ensure the site uses HTTPS (required for PWA). Check browser console for manifest errors.
Push notifications not arriving VAPID keys not configured, or notification permission blocked Check VAPID keys in .env; check device notification permissions for the browser/app.
App shows old/stale content Service worker serving cached files after an update Open the app, wait 30 seconds for the new service worker to activate, then reload. Or clear cache manually.
iOS: No notification permission prompt App was opened from browser tab, not home screen icon Close the browser. Open the app from the home screen icon. The permission prompt only shows when launched as a standalone PWA.
Offline mode shows blank screen Service worker not registered (first visit, no cache yet) Visit the dashboard online at least once to populate the cache before going offline.
Desktop: Install icon not visible in Chrome address bar App already installed, or browser recently dismissed the prompt Go to Chrome Settings → Apps → find the dashboard → or check chrome://apps/
Android: Banner appeared but I dismissed it accidentally Chrome hides the banner for 90 days after a dismissal Use the manual install method: Chrome menu (⋮) → Add to Home screen.
Notifications arrive but tapping them does nothing PWA is not set as the default handler for the notification click Uninstall and reinstall the PWA. On Android, ensure Chrome is not in "lite" mode.
💡

If you are a developer debugging PWA issues, open Chrome DevTools → Application tab → check the Manifest, Service Workers, and Storage sections. This shows the exact state of the PWA installation and any errors.
