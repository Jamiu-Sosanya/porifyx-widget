⚙️ Installation Guide

Install PoriFyx Widget

This guide is written for non-developers. You do not need to know any programming. Follow each step in order and your platform will be live in under 10 minutes. The built-in browser installer does all the hard work for you.

2 Upload the Files

You received a ZIP file from PoriFyx. Extract it on your computer — you will see the full project folder inside.

  1. 1

    Extract the ZIP

    Right-click the downloaded ZIP and choose Extract All (Windows) or double-click (Mac). You will get a folder containing app/, public/, routes/, and other Laravel directories.

  2. 2

    Upload via cPanel File Manager or FTP

    Option A — cPanel File Manager: Log into cPanel → File Manager → navigate to public_html (or your domain folder) → Upload the extracted folder contents there.

    Option B — FTP (FileZilla): Connect to your server using your FTP credentials. Drag and drop the extracted folder contents into your domain's root directory.

  3. 3

    Verify the structure

    After upload, your domain root (public_html/) should contain these top-level items:

    public_html/ ├── app/ ├── bootstrap/ ├── config/ ├── database/ ├── public/ ← contains index.php ├── resources/ ├── routes/ ├── storage/ ├── vendor/ ← PHP dependencies (must be present) ├── .htaccess ← root rewrite rule (already included) ├── artisan └── composer.json
    ⚠️

    The vendor/ folder is large (~100 MB) but must be present. If it is missing from the package, install it locally with composer install --no-dev and then upload it, or use your host's Composer tool.

3 Create the .env File

The .env file stores your site's private configuration — database credentials, app URL, and secret keys. Never share this file publicly.

  1. 1

    Create a MySQL Database

    In cPanel → MySQL Databases: create a new database (e.g. mysite_aichat), create a database user with a strong password, and grant that user All Privileges on the database. Write down the database name, username, and password.

  2. 2

    Copy .env.example to .env

    In File Manager, find .env.example in the root. Right-click → Copy → paste it in the same folder. Rename the copy to exactly .env (no extension).

    ℹ️

    On some hosts, files starting with a dot are hidden by default. In File Manager, click the Settings button and enable Show Hidden Files.

  3. 3

    Edit the .env file

    Right-click .env → Edit. Update the following lines at minimum:

    APP_NAME="My AI Chat" APP_ENV=production APP_KEY= # leave blank — installer will generate this APP_DEBUG=false APP_URL=https://yourdomain.com DB_CONNECTION=mysql DB_HOST=localhost DB_PORT=3306 DB_DATABASE=mysite_aichat DB_USERNAME=mysite_user DB_PASSWORD=your_strong_password

4 Set File Permissions

Laravel needs write access to two folders. Set them in File Manager by right-clicking each folder and choosing Change Permissions.

FolderPermissionWhy
storage/775Logs, session files, compiled views, and file uploads are stored here
bootstrap/cache/775Framework caches configuration and routes here for speed
💡

Set permissions recursively so all sub-folders inside storage/ are also writable. In cPanel File Manager, tick the Recurse into subdirectories checkbox when setting permissions.

5 Run the Browser Installer

Open your web browser and visit:

https://yourdomain.com/install

If you installed in a sub-folder (e.g. public_html/chat/) use:

https://yourdomain.com/chat/install
⚠️

If you see a 404 Not Found page, the .htaccess file is probably not being read by Apache. Check with your host that mod_rewrite is enabled and that AllowOverride All is set for your document root.

6 Installer Wizard — Step by Step

The installer walks you through 7 steps. Each step must pass before you can continue.

  1. 1

    Welcome Screen

    Confirms the installer is loading correctly. Click Begin Installation to proceed.

  2. 2

    Requirements Check

    The installer checks your PHP version and all required extensions. Each item shows a green tick or red cross. If anything is red, contact your hosting support and ask them to enable the listed PHP extension.

  3. 3

    Permissions Check

    Verifies that storage/ and bootstrap/cache/ are writable. If either shows a red warning, go back and set the folder permissions to 775 as described in Step 4.

  4. 4

    Environment Configuration

    Enter (or confirm) your App URL and Database credentials. The installer will test the connection before allowing you to proceed. If the connection test fails, double-check the database name, username, password, and host.

  5. 5

    Database Setup

    The installer runs all database migrations (creates 35+ tables) and seeds default data including a free plan, default system settings, and notification templates. This takes 10–30 seconds. Do not close the browser.

    💡

    You can optionally enable Demo Data here. This seeds sample widgets, conversations, and leads so you can explore the interface immediately without creating everything from scratch.

  6. 6

    Create Admin Account

    Enter a name, email address, and a strong password (at least 8 characters, mix of letters, numbers, and symbols). This account will be the super-administrator with access to every part of the platform.

    ⚠️

    Write down this email and password. There is no "forgot password" link for the admin panel — recovery requires direct database access.

  7. 7

    Installation Complete

    The installer writes INSTALLATION_COMPLETE=true to your .env file and locks the installer so it cannot be run again. You will see links to your dashboard and admin panel.

7 After Installation — First Steps

With the installer complete, log in and complete these post-install steps:

🔑 Log In

Go to https://yourdomain.com/login and sign in with the admin email and password you just created.

⚙️ Admin Panel

Access the super-admin panel at https://yourdomain.com/admin. This is separate from the user dashboard and has additional management tools.

📋 Create a Plan

Go to Admin → Plans and create at least one subscription plan. Users need a plan to create widgets. You can also make a free plan with generous limits.

🏷️ Branding

Go to Admin → Settings → Branding. Set your app name, upload a logo, and configure support email. This applies site-wide.

9 Push Notifications (VAPID Keys)

Browser push notifications let your team receive real-time alerts — new leads, escalated conversations, and chat events — without keeping the dashboard tab open. They require a pair of VAPID keys (Voluntary Application Server Identification), which prove your server is allowed to send pushes to subscribed browsers.

💡

Auto-generated during installation. The web installer generates your VAPID keys automatically during the Environment Configuration step and writes them directly into your .env file. On most Linux servers you do not need to do anything manually — the keys are ready the moment installation completes.

Verify the Keys Were Generated

Open your .env file and look for these three lines. They should contain values, not be empty:

VAPID_PUBLIC_KEY=BNxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx VAPID_PRIVATE_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx VAPID_SUBJECT=mailto:admin@yourdomain.com VITE_VAPID_PUBLIC_KEY="${VAPID_PUBLIC_KEY}"

Generate Keys Manually (if empty)

On some servers (older PHP builds or restrictive hosting), the installer may not be able to generate VAPID keys automatically. If the lines above are blank, generate them manually by running this single command via SSH or your host's terminal:

php artisan webpush:vapid

The command generates a fresh key pair and writes all three values (VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_SUBJECT) directly into your .env file. It also prints the public key to the terminal so you can confirm it was set.

After running the command, clear the config cache so the app picks up the new values immediately:

php artisan config:clear
⚠️

Never reuse VAPID keys across multiple apps. Each deployment should have its own unique key pair. Reusing keys can cause push delivery failures because the browser associates the public key with a specific server identity. If you re-run the installer on a clean install, new keys are generated automatically.

Requirements for Key Generation

RequirementWhy
OpenSSL extension (PHP)Used to generate the EC P-256 key pair that VAPID requires
OpenSSL compiled with EC supportMust support the prime256v1 elliptic curve — standard on all modern Linux distributions
HTTPS on your domainBrowsers only allow push subscriptions on HTTPS origins
ℹ️

Push notifications work entirely in the browser — no app store, no native app required. Users visit your dashboard, allow notifications when prompted, and then receive alerts as standard OS notifications even when the tab is closed.

10 Real-time Chat (Reverb WebSocket)

Live chat between your agents and visitors is powered by Laravel Reverb, a self-hosted WebSocket server. The installer generates random Reverb credentials automatically — you just need to start the server process.

💡

Auto-generated during installation. REVERB_APP_ID, REVERB_APP_KEY, and REVERB_APP_SECRET are all generated with cryptographically random values when you run the installer. You do not need to create or copy these values manually.

Verify the Credentials Were Generated

Open your .env file. These should contain random values, not the placeholders your-app-id / your-app-key:

BROADCAST_CONNECTION=reverb REVERB_APP_ID=481293 # a random 6-digit number REVERB_APP_KEY=qyzmxnftaelwbdcr # 20-character random string REVERB_APP_SECRET=hkpvdnzocrmfsate # 20-character random string REVERB_HOST="localhost" REVERB_PORT=8080 REVERB_SCHEME=http

Starting the Reverb Server

Reverb is a long-running process — run it on your server via SSH and keep it alive with Supervisor or a process manager:

php artisan reverb:start

Production Reverb Setup (Supervisor)

On a VPS or dedicated server, add this to your Supervisor config so Reverb restarts automatically if it crashes:

[program:reverb] process_name=%(program_name)s command=php /var/www/html/artisan reverb:start autostart=true autorestart=true user=www-data redirect_stderr=true stdout_logfile=/var/log/reverb.log
ℹ️

Shared hosting: Most shared hosting providers do not allow long-running processes. If you are on shared hosting, real-time chat delivery via WebSocket may not be available. Contact your host to check whether persistent processes are supported, or upgrade to a VPS plan.

11 Connect Stripe Billing (Optional)

If you plan to charge users a subscription fee, connect Stripe. If you are using this for yourself only, you can skip this step.

  1. 1

    Create a Stripe Account

    Sign up at stripe.com and verify your business details to enable payouts.

  2. 2

    Get API Keys

    In Stripe Dashboard → Developers → API Keys. Copy the Publishable key and Secret key.

  3. 3

    Add Keys to .env

    STRIPE_KEY=pk_live_xxxxxxxxxxxx STRIPE_SECRET=sk_live_xxxxxxxxxxxx STRIPE_WEBHOOK_SECRET=whsec_xxxxxxxxxxxx
  4. 4

    Set Up Webhook

    In Stripe Dashboard → Developers → Webhooks → Add endpoint. Set the URL to https://yourdomain.com/stripe/webhook. Select events: customer.subscription.created, customer.subscription.updated, customer.subscription.deleted, invoice.payment_succeeded, invoice.payment_failed.

12 Troubleshooting

Common Problems and Fixes

ProblemMost Likely CauseFix
White page / 500 errorAPP_DEBUG=false hides detailsTemporarily set APP_DEBUG=true in .env, refresh, read the error, then set back to false
404 on /installmod_rewrite not enabled or .htaccess missingAsk host to enable mod_rewrite; confirm .htaccess is in the root
Database connection failedWrong credentials or hostVerify DB_DATABASE, DB_USERNAME, DB_PASSWORD in .env; check DB_HOST (often localhost)
Permission denied errorstorage/ not writableSet storage/ and bootstrap/cache/ to permission 775 recursively
Installer runs again after completionINSTALLATION_COMPLETE missing from .envAdd INSTALLATION_COMPLETE=true to .env manually
Missing CSS / JS (blank-looking pages)Build assets missingCheck that public/build/ folder exists. If missing, run npm run build locally or re-upload it.
Email not sendingSMTP not configuredSet MAIL_HOST, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD in .env. Use SMTP from your host or a service like Mailgun or Postmark.
AI not respondingInvalid or missing API keyGo to Admin → Settings → AI Configuration and verify your API key. Test with the "Test AI" button.
