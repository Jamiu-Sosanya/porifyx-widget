Admin Guide

The Super-Admin panel gives you complete control over every user, plan, channel, widget, conversation, and system setting on your platform. This guide explains every screen in plain language so you can run your SaaS business confidently — no technical background required.

1 Accessing the Admin Panel

The admin panel is a completely separate area of the application, accessible only to accounts that have been granted the super-admin role during installation or by another super-admin.

💡

Where is it? Navigate to https://yourdomain.com/admin. If you are already logged in as a regular user, you will be redirected — the admin panel does not share a session with the regular dashboard.

Logging In

  1. 1
    Go to https://yourdomain.com/admin/login.
  2. 2
    Enter the super-admin email and password you set during installation. These are different from regular user credentials.
  3. 3
    If Two-Factor Authentication is enabled for your admin account, you will be prompted for the 6-digit TOTP code from your authenticator app.
  4. 4
    You land on the Admin Dashboard. A dark sidebar on the left shows all admin navigation sections.
⚠️

Protect your admin credentials. Use a unique, long password for the super-admin account. Enable Two-Factor Authentication immediately after first login. Anyone with admin access can read all user data, change billing plans, and delete accounts.

Promoting a User to Super-Admin

You can grant admin access to additional team members from Admin → Users → Edit User → Role → Super Admin. Only do this for trusted team members — there is no partial admin role; super-admin has full access to everything.

Charts on the Dashboard

  • User Signups (30 days) — Daily bar chart showing new registrations. Spikes indicate marketing campaigns working.
  • Message Volume (30 days) — Line chart of total messages per day. Downward trends may indicate service issues.
  • Revenue by Plan — Doughnut chart showing what percentage of MRR comes from each billing tier.

3 User Management

Go to Admin → Users to see every account registered on your platform. This is where you manage subscriptions, resolve account issues, and handle support requests that require admin access.

The Users Table

The table shows: Name, Email, Plan, Status (Active / Suspended / Unverified), Number of Widgets, Joined Date, and Last Login. You can:

  • Search — type in the search box to find users by name or email instantly.
  • Filter by Plan — use the dropdown to show only Free, Starter, Pro, or Enterprise users.
  • Filter by Status — show only active, suspended, or unverified accounts.
  • Sort — click any column header to sort ascending/descending.
  • Export — download the full user list as a CSV file for external reporting.

Viewing a User's Profile

Click any user's name to open their full profile page. This shows:

📋

Account Details

Name, email, registration date, last login, IP address, timezone, and email verification status.

💳

Billing Info

Current plan, billing cycle, Stripe Customer ID, next renewal date, payment history, and any active discounts.

🤖

Widgets & Channels

All widgets the user has created, their channel connections, and total message counts per widget.

📊

Usage Stats

Total messages used this billing period, leads captured, knowledge base entries, and storage used.

Editing a User

Click the Edit button on a user profile to change:

FieldWhat It Does
Name / EmailUpdate contact information (email change requires re-verification)
PlanManually upgrade or downgrade without going through Stripe checkout
Plan ExpiryExtend or shorten a user's billing period manually
RoleSet to User or Super Admin
StatusActive, Suspended, or Banned
Message Limit OverrideGrant extra messages beyond the plan limit for a specific user
NotesInternal admin notes (never shown to the user)

Suspending a User

Suspending an account immediately prevents that user from logging in and stops their widgets from responding to visitors. Their data is preserved — you can re-activate at any time. Use suspension for:

  • Failed payments (while waiting for the user to update their card)
  • Abuse reports or terms-of-service violations
  • Pending verification on high-risk signups
⚠️

Suspension vs. Deletion: Suspension is reversible. Deletion permanently removes the account, all widgets, all conversations, all leads, and all knowledge base data. There is no undo. Always suspend first, delete only after confirming the user does not want their data back.

Impersonating a User

Click Login as User on any user's profile to temporarily log into the dashboard as that user. This lets you:

  • Reproduce issues the user reported without needing their password
  • Configure things on their behalf as a managed service
  • Verify that billing changes took effect correctly

A red banner at the top of the screen reminds you that you are in impersonation mode. Click Return to Admin to exit. All impersonation sessions are logged in the Audit Log.

Sending a Password Reset

Click Send Password Reset Email on a user's profile to trigger a reset link to their inbox. Useful when a user is locked out and cannot use the "forgot password" flow themselves.

Manually Verifying Email

If a user did not receive their verification email, click Mark Email Verified to verify their address manually and allow them to log in.

4 Billing Plan Management

Go to Admin → Plans to create, edit, and delete the subscription tiers that users purchase. Plans define what features users can access and how many resources (messages, widgets, channels) they get.

Creating a New Plan

  1. 1
    Go to Admin → Plans → Create Plan.
  2. 2
    Fill in the plan name (e.g. "Starter"), a short description, and a display colour/icon.
  3. 3
    Set the monthly price and (optionally) a discounted annual price. Both values are in your configured currency.
  4. 4
    Create the matching product and price in your Stripe dashboard, then paste the Stripe Price ID into the plan form.
  5. 5
    Set the plan limits (see table below).
  6. 6
    Toggle the feature switches — enable or disable specific features for this plan tier.
  7. 7
    Click Save Plan. The plan immediately appears on the public pricing page and in checkout.

Editing and Deleting Plans

You can edit any plan at any time. Changes to limits take effect immediately for all users on that plan. Changing the price does not affect existing subscribers; it only affects new signups.

⚠️

Deleting a Plan: You cannot delete a plan that has active subscribers. First move all subscribers to another plan, then delete. Alternatively, mark the plan as "Hidden" to prevent new signups while keeping existing subscribers.

Free Plan

Every platform has a default "Free" plan. Users who do not purchase a subscription are automatically placed on this plan. Configure it conservatively — for example 1 widget, 100 messages/month, no external channels — to incentivise upgrades.

5 Widget Oversight

Go to Admin → Widgets to see every widget created across all user accounts. This is useful for spotting misuse, helping users debug, and understanding which widgets are most active.

Widget List

The table shows: Widget Name, Owner (user), Status (Active/Paused), Total Conversations, Total Messages, Channel Count, and Creation Date. You can search by widget name or filter by owner.

Widget Detail View

Click a widget to open its read-only detail view. The detail view shows:

  • All widget settings (appearance, AI model, system prompt)
  • Knowledge base items linked to the widget
  • Active channels and their connection status
  • Recent conversations (last 20)
  • Lead capture summary

Disabling a Widget

If a widget is being used to spread spam or violate terms, you can disable it from the admin panel without suspending the whole user account. Go to Widget Detail → Disable Widget. The widget stops responding immediately. The user sees a notice in their dashboard.

Disabling a Channel

If a channel is causing abuse or excessive traffic, you can disable it from the admin panel. The user's widget continues on other channels; only the specific problematic channel is stopped.

Webhook Health Check

For each external channel (WhatsApp, Telegram, Facebook, etc.), the admin panel shows the webhook status: Connected, Pending Verification, or Failed. A "Failed" webhook means messages are not reaching the AI. Click Re-register Webhook to attempt automatic re-registration.

7 Conversation Management

Go to Admin → Conversations to search and view any conversation on the platform. This is used for support escalations, abuse investigations, and quality audits.

⚠️

Privacy Notice: Reading user conversations for reasons other than support, abuse investigation, or legal compliance may violate privacy regulations (GDPR, CCPA). Always document why you accessed a conversation.

Search and Filters

  • Search by conversation ID, visitor email/phone, or message keyword
  • Filter by date range, channel type, widget owner, status (open/closed/escalated)
  • Filter by sentiment (positive, neutral, negative) — useful for finding problem conversations
  • Filter by CSAT score — find low-rated conversations to identify AI quality issues

Conversation Detail View

Each conversation shows the full message thread, timestamps, the channel it came from, the AI model used, the knowledge base items retrieved, and any leads captured. You can add an admin note that is never shown to the user.

Deleting Conversations

Under GDPR's "right to be forgotten", you may need to delete conversations containing a visitor's personal data. Go to the conversation, click Delete Permanently. This removes the conversation and all associated lead records. The action is logged in the Audit Log.

9 Broadcasts

Go to Admin → Broadcasts to send in-dashboard notification banners to all users or a specific segment.

Creating a Broadcast

  1. 1
    Go to Admin → Broadcasts → New Broadcast.
  2. 2
    Write your message (supports bold and links). Choose a type: Info (blue), Success (green), Warning (amber), or Alert (red).
  3. 3
    Choose the audience: All Users, Users on a Specific Plan, or Users who signed up before/after a date.
  4. 4
    Set an optional expiry date — after this date the banner disappears automatically.
  5. 5
    Click Send Broadcast. The banner appears for all targeted users on their next page load.

10 System Health & Queues

Go to Admin → System to monitor your server and the background job workers that process AI requests, webhooks, emails, and analytics.

Queue Dashboard

✅

Completed Jobs

Background jobs that finished successfully. A healthy platform processes thousands per hour.

⏳

Pending Jobs

Jobs waiting to be processed. A growing backlog means workers cannot keep up — scale up your server.

❌

Failed Jobs

Jobs that threw an error. Click to see the error and retry. Common causes: expired API keys, rate limits, invalid data.

⚡

Throughput

Jobs processed per minute. A sudden drop means a queue worker has crashed.

Server Health Panel

Maintenance Commands

Common operations triggerable from the admin panel without needing terminal access:

  • Clear Cache — flushes the application cache. Run if config changes are not taking effect.
  • Clear Queue — removes all pending jobs. Use only during maintenance windows.
  • Rebuild Search Index — re-indexes all knowledge base content for AI retrieval.
  • Run Pending Migrations — applies any database migrations needed after an update.
  • Storage Link — re-creates the public/storage symlink if uploaded files are not accessible.
💡

If a user reports something "not working", check System → Logs filtered to "error" level around the time of the reported issue — that is almost always where you will find the cause.

Feature Flags

Turn platform-wide features on or off without deploying code:

  • Omnichannel Channels — disable to hide all channel settings platform-wide
  • A/B Testing — disable to remove A/B test UI from all dashboards

  • Lead Scoring — disable if the scoring model needs recalibration

Paste custom CSS into the Custom CSS textarea to change fonts, colours, or spacing on any page. It is injected after the default stylesheet so your rules take precedence.

Email Templates

Go to Admin → Branding → Email Templates to customise the HTML of every automated email: welcome, password reset, lead notification, plan upgrade, and payment receipt. Use placeholders like {{user_name}} and {{platform_name}} which are replaced with real values at send time.

13 Security & Audit Logs

Audit Log

Every sensitive action is recorded automatically: admin logins, impersonation sessions, user suspensions/deletions, plan changes, data exports, and settings changes. Each entry shows the date/time, admin user, action, affected resource, and IP address.

Security Settings

SettingRecommendation
Require 2FA for AdminsAlways enable — prevents account takeover even with a stolen password
Admin Session TimeoutSet to 30–60 minutes of inactivity
IP Allowlist for AdminRestrict admin login to your office or VPN IP addresses
Failed Login LockoutLock account after 5 failed attempts; send alert email
API Key ExpiryExpire user API keys every 90 days
CORS PolicyRestrict widget embed to specific domains to prevent unauthorised use

GDPR & Data Compliance

  • User Data Export — export all data for a user as a ZIP file (fulfils GDPR subject access requests)
  • User Data Deletion — permanently delete all data for a user (fulfils GDPR right to erasure)
  • Consent Log — the widget records a timestamp when a visitor gives consent, stored per conversation
  • Data Retention Policy — configure automatic deletion of conversations and leads older than N days, per plan
